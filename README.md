# Fraud ML Platform

End-to-end Machine Learning platform for credit card fraud detection, designed to simulate a real production ML system.

This project demonstrates how Machine Learning models move from research to production using modern MLOps practices.

## Project Goals

Build a full ML lifecycle pipeline including:

- Data ingestion and preprocessing
- Feature engineering
- Model training and evaluation
- Model serving through APIs
- Containerization with Docker
- Monitoring and drift detection
- Production deployment strategies

## Technologies

- Python
- Scikit-learn
- XGBoost / LightGBM
- FastAPI
- Docker
- MLflow
- GitHub Actions
- SHAP (Model Explainability)
